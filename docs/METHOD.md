# Method note — private partial research handoff

**PARTIAL_NOT_JUDGE_READY.** Software verification is not legal validation, an official score,
or permission to submit. This note describes the saved export; packaging does not repair its gaps.

Original captured sources feed structured rules, exact quotes and separate provenance/evidence
checks. The shared evaluator uses property facts, legal geography and an explicit date. Unknown
facts, uncertain dates, missing support and conflicts remain explicit. User answers are unverified,
request-local inputs; they do not overwrite saved facts. Hypothetical enactment is separate from
actual-law results. Source identity, quote matching and valid anchors do not prove legal support.

The seven JSON payloads and original export run manifest are copied byte-for-byte from a saved
software verification run. A second, distinct run produced the same seven payload hashes.
`provenance/` retains both the verification report and the release/snapshot identities; the replay
run manifest is also retained. `handoff.json` hashes every included file and records code, data,
source-catalog and export-input identities. The packager makes no network or model calls and runs
no rule evaluation. Its integrity checks neither refresh the corpus nor reassess legal truth.

`changes.json` preserves the official projection; `change_details.json` preserves uncertainty and
blocked/partial status. An empty definite set in a blocked case is not evidence of no impact.
`validation.json` retains coverage gaps, errors, warnings and the false submission-readiness flag.
Review-needed rules and unresolved municipalities still require their owners' review.

Retain the trusted manifest hash separately and run the documented handoff verifier after copying.
The full frozen runnable release and source stores remain separate private artifacts; this handoff
is not a self-contained evaluator runtime. The recorded software/browser checks describe that
saved release, not a new run by the packager. Independent source/legal review, complete evidence,
UX acceptance and explicit human release approval remain separate gates.
